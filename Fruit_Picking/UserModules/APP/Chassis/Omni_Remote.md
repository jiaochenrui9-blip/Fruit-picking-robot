# 底盘速度解算（全向轮 / 麦轮）

- `Omni_Remote.c`、`Mecanum_Remote.c` 各有一个更新函数，函数里不读遥控，指令从参数 `command` 传进来；用法相同，换底盘只换函数名。
- 各底盘的参数宏写在各自的 `.c` 开头，实测后修改；`Chassis_Command.h` 只有轮数、结构体和函数声明。

## 用法

```c
Chassis_Speed_t ChassisSpeed;

/* 控制节拍（TIM8 中断）里：传主循环发布出来的那份指令（见 UserModules/Task/BareMetal.c） */
Omni_Remote_Update(&ChassisSpeed, &chassis_command);   // 麦轮底盘换成 Mecanum_Remote_Update
// 全向轮 ChassisSpeed.wheel_rpm[0..3]：右前、右后、左后、左前，对应电调 ID1~4
// 麦轮函数仍为原顺序：前左、后左、后右、前右；切换时需匹配电调编号
```

在中断里调用时，不要直接传 `Chassis_Remote_GetCommand()`：主循环里的 `Chassis_Remote_Update()` 是逐字段写那份指令的，中断打断在中间就会读到半新半旧的一条。

## 计算过程

1. 指令 vx、vy、wz（-1~1；遥控控制时已含死区和档位）乘各自的上限，得到车体速度：
   平移 `VXY_MAX`（m/s），旋转 `WZ_MAX`（rad/s）。vx 向右、vy 向前，wz 顺时针为正。
2. 算出每个轮子的线速度（m/s），旋转部分 = 距离 × 角速度。
3. 乘 `k = 60 / 2π / 轮半径 × 减速比`，换成转子转速 rpm。
4. 任一轮超过 `RPM_MAX` 时，四个轮等比例缩小，合成运动方向不变。

输出是乘电机方向 dir 之前的逻辑方向：全向轮正值表示该轮推动车体顺时针转，麦轮正值表示该轮向前滚动。

## 公式（轮速 m/s）

全向轮电调 ID1~4 从右前开始顺时针编号：右前、右后、左后、左前。
驱动方向角 θ 从右边逆时针量，逻辑正转沿顺时针切向：

| 电调 ID / 下标 | 位置 | 轮子位置角 | 驱动方向角 θ |
| --- | --- | --- | --- |
| ID1 / 0 | 右前 | 45° | 315° |
| ID2 / 1 | 右后 | 315° | 225° |
| ID3 / 2 | 左后 | 225° | 135° |
| ID4 / 3 | 左前 | 135° | 45° |

位置角与驱动方向角相差 90°，不能直接把轮子位置角填入 `wheel_theta`。

```
v = cos(θ)·vx + sin(θ)·vy + R·wz
```

按 ID1~4 顺序，前进的逻辑轮速符号为 `− − + +`，右移为 `+ − − +`，顺时针旋转为 `+ + + +`。
这些符号是乘电机方向 `dir` 之前的目标；实际安装方向需上板核对。

麦轮（X 型安装）：

```
前左 = vy + vx + (LX+LY)·wz
后左 = vy - vx + (LX+LY)·wz
后右 = vy + vx - (LX+LY)·wz
前右 = vy - vx - (LX+LY)·wz
```
